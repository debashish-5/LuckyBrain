# Security Policy

LuckyBrain is in early development. Do not use it to process sensitive data in production without independently reviewing the code and integrations.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Report them privately through GitHub's **Report a vulnerability** feature for this repository when it is enabled. Include affected versions or commits, impact, and reproduction steps when safe to share. Maintainers will acknowledge reports and coordinate a fix and disclosure.

Do not include real credentials, personal data, or customer data in a report. If private reporting is unavailable, contact a repository maintainer directly and request a secure channel.
